# Ship Detection from Satellite Imagery using Deep Learning

Monitoring activity at sea is important for maritime security, environmental protection, and global trade analysis. One key task is identifying ships from remote sensing imagery. This project focuses on building a Deep Learning model that can automatically detect whether a target in satellite imagery is a ship or not.

Traditionally, ship tracking relies on the Automated Identification System (AIS). AIS uses VHF radio signals to broadcast a ship’s location, identity, and destination to nearby ships and land-based receivers. While AIS is very useful, it has an important limitation. It can only track ships that actively transmit their signal. Ships that disable their transponders or do not carry AIS cannot be detected through this system.

Satellite imagery offers another powerful source of information. Modern satellite providers such as Planet operate constellations of small satellites that capture images of the entire Earth every day. This creates an enormous amount of visual data. However, manually inspecting such a large volume of images is nearly impossible.

This is where machine learning and computer vision become essential.

In this project, a deep learning model is developed to automatically analyze satellite images and detect large ships. By automating this process, organizations can monitor maritime activity more efficiently and at a much larger scale.

Such technology can support several real-world applications, including:

• Maritime traffic surveillance
• Detection of illegal fishing activities
• Oil spill and pollution monitoring
• Port activity analysis
• Supply chain and logistics monitoring

By combining satellite imagery with deep learning, this project aims to make ship detection faster, smarter, and more scalable.
